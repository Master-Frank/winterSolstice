# 冬至·团圆局 (winterSolstice)

冬至主题暖色治愈 H5 互动小游戏 + 暖心祝福留言板。本项目通过两个核心模块，为用户提供一个充满仪式感的冬至线上体验：你可以亲手“包”一只饺子，也可以在“锅”里留下你的暖心祝福。

---

## 🌟 项目模块详解

本项目包含两个主要功能入口，分别对应不同的互动场景：

### 1. 🥟 云包饺子 (Cloud Dumpling)
**路径**: `/cloud/`
这是一个沉浸式的互动小游戏，引导用户完成冬至包饺子的全过程。
- **互动流程**: 
  - **和面**: 揉搓面团，开启冬至序幕。
  - **擀皮**: 亲手制作饺子皮。
  - **包馅**: 提供 9 种不同含义的馅料（如猪肉、牛肉、虾仁、玉米等），每种馅料对应一种独特的人格特质（如“细腻浪漫型”、“爽朗直球型”等）。
  - **下锅**: 完成包制，等待饺子成熟。
- **核心功能**:
  - **人格标签**: 根据选择的馅料组合，生成专属的“人格关键词”和“冬至评价”。
  - **随机祝福**: 从 30+ 条治愈系祝福语中随机抽取一条送给用户。
  - **分享卡片**: 生成包含二维码和个性化评价的分享图，方便转发朋友圈。

### 2. 🍲 冬至暖心祝福留言板 (Blessing Board)
**路径**: `/dumpling/`
这是一个社区互动板块，用户可以将祝福化作“饺子”投入大锅中。
- **互动场景**: 
  - **祝福墙**: 页面以一口冒着热气的“锅”为背景，每一条祝福都化作一只漂浮的饺子。
  - **提交祝福**: 用户可以输入 200 字以内的祝福语。
  - **互动体验**: 点击锅里的饺子会弹出精美的祝福卡片；页面伴有动态雪花和蒸汽效果，营造冬日氛围。
- **核心功能**:
  - **实时统计**: 显示全网累计提交的祝福数量。
  - **动态展示**: 祝福语随机/轮播展示，让每一份温暖都能被看见。
  - **进度反馈**: 随着祝福数量增加，系统会给出不同的暖心文案（如“锅里开始热闹了”）。

## 🛠️ 技术栈

- **前端**: 
  - 原生 HTML5 & CSS3 (Flex/Grid 布局，响应式适配移动端)。
  - 原生 JavaScript (ES6+)，无第三方重型框架，保证极速加载。
  - 动态效果：CSS Animation + 蒸汽/雪花粒子模拟。
- **后端**: 
  - Node.js + Express 框架。
  - 接口限流与安全性优化。
- **数据库**: 
  - **Supabase (PostgreSQL)**: 存储祝福留言与参与人数统计。
- **部署**: 
  - 支持 Docker 容器化。
  - 静态资源与 API 服务统一由 Express 托管。

## 🚀 快速开始

### 1. 环境准备
确保已安装 Node.js (v16+)。

### 2. 安装与配置
```bash
npm install
cp .env.example .env
```
在 `.env` 中填入你的 `SUPABASE_URL` 和 `SUPABASE_SERVICE_ROLE_KEY`。

### 3. 数据库初始化
将 `supabase/migrations/` 下的 SQL 脚本粘贴到 Supabase 的 SQL Editor 中运行，以创建 `participants` 和 `blessings` 表。

### 4. 启动
```bash
npm start
```
访问 `http://localhost:3000` 即可开启冬至之旅。
